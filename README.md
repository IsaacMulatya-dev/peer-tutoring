Peer Tutoring Platform

Overview
A web-based peer tutoring system designed to help students connect with tutors, schedule sessions and share learning resources within an academic environment.

Technologies Used
- HTML5
- CSS3
- JavaScript

Key Features
- User-friendly interface for tutors and students
- Subject-based tutor discovery and matching
- Session booking and schedules management
- Clean and responsive web design

Setup Instructions

Clone the repository:
git clone https://github.com/IsaacMulatya-dev/peer-tutoring.git

Navigate to the project folder:
cd peer-tutoring

Open index.html directly in your web browser or use a local development extension like Live Server in Visual Studio Code.
